01 — The challenge

Build an agent that uses real software_

Join H Company and 42AI for an in-person hackathon dedicated to AI agents that interact with real software and get things done.

Build an agent that can navigate websites, desktop apps, and software interfaces to complete a meaningful real-world task. Pick a use case, build it, and show it working.

H Company brings its Agents API and specialized models. Explore the docs before the weekend and come ready to build. Aim for a working demo that clearly shows the problem, the actions your agent takes, and the result.

With the support of Gladia, Linkup, Cognition (Devin), Stripe, and Morning.

  • API credits and access to partner tools
  • 1:1 mentorship from H Company researchers and engineers
  • On-site technical support and fellow builders to connect with
  • Meals, snacks, drinks, and closing networking
