# Meetin-OS Windows 0.1.1, version de test

Extraire le ZIP, puis ouvrir Meetin-OS-Windows-0.1.1.exe sur Windows 10/11 x64 avec .NET Framework 4.8. Installateur de test non signé. Le manifeste indique le commit et l’empreinte SHA-256 ; les propriétés du fichier et Applications installées affichent 0.1.1. Fermer Meetin-OS avant de réinstaller ; les enregistrements restent dans LOCALAPPDATA/Meetin-OS/Recordings.

Vérifier ouverture depuis Démarrer, enregistrement manuel court avec deux pistes, arrêt puis transcription avec une clé Gladia de session. La piste micro doit porter le nom Windows ou Vous. Voir les pistes doit retrouver les fichiers. Ce parcours audio nécessite un vrai PC et reste à recetter par Samy.

Cette mise à jour contient le code Windows disponible et le correctif de nom de Samy. Elle ne porte pas les fonctions SwiftUI Mac : connexion Google native, agent natif/réactif, pause/reprise, historique avec gestion des réunions, cartes de facturation, lecteur intégré et pastille flottante ne sont pas livrés sur Windows. L’espace agent web historique n’est pas une alternative au nouvel agent Mac.

Le workflow Windows régénère cet installateur, contrôle sa version, installe ce même fichier, ouvre sa fenêtre et vérifie sa désinstallation avant publication de l’artefact. Il ne prouve pas la capture de deux voix réelles ni la qualité Gladia.
